# ANUJ VERSE

A premium, responsive landing page for the ANUJ VERSE software platform and AURA product family. Built with plain HTML, CSS, and JavaScript for GitHub Pages.

## Run locally

Open `index.html` in a browser, or serve this directory with any static file server.

## Publish on GitHub Pages

In the repository settings, enable GitHub Pages and select the `main` branch and `/ (root)` as the publishing source.

## Configure official links

The AURA LAUNCHER download link is intentionally unset so the site does not point visitors to a fake download. When an official URL is available, set `PRODUCT_DOWNLOAD_URL` in `script.js`. The Discord invite is likewise shown as coming soon until an official invite is ready.

The hero and feature panels are original CSS interface concepts, not screenshots of a released product.
